## Le jeu

Bonjour et bienvenue dans « Les Enquêtes Toxiques ».
Vous incarnez Jones Philibert, médecin légiste exerçant à Londris, une capitale paisible où l'ordre règne.

Cependant, depuis quelques années, l'ordre et la paix ont laissé place à une vague de décès sans précédent. Le taux de mortalité ne cesse d'augmenter, et ce malgré les efforts constants de la police.

Submergée par les affaires, celle-ci décide de vous demander d'autopsier 3 cadavres afin de déterminer les causes de leur décès.

Ces morts sont-elles liées ? S'agit-il de cas isolés ?

C'est à vous de le découvrir…

## Votre mission

Vous devrez examiner les cadavres, comparer les blessures à l'aide de vos documents et établir les causes de leurs morts avant de rendre vos conclusions à la police.

Pour accomplir votre mission, vos documents seront vos meilleurs alliés. Vous aurez à votre disposition :

- **La Gazette**, utile pour s'informer sur la vie de tous les jours ;
- **L'Herbier**, un recueil de plantes toxiques que vous avez décidé de commencer récemment ;
- **Le Recueil des Blessures Externes**, pratique pour identifier rapidement les lésions externes ;
- **Le Recueil des Blessures Internes**, efficace pour comparer l'apparence originale des organes.

## Contrôles

- **Clic droit** sur les livres pour les ouvrir lorsqu'ils sont hors de l'inventaire ;
- **Maintenir clic gauche** pour glisser les livres dans ou hors de l'inventaire ;
- **Clic gauche** pour interagir avec le monde ;
- Pour comparer les blessures, cliquez sur une partie interactive d'un cadavre, puis sur la partie interactive du livre qui vous semble correspondre à la blessure.
